# QB Sense VR Prototype

QB Sense VR is a quarterback-training web-app prototype. It demonstrates how quarterbacks could practice blitz recognition, pocket pressure, progression reads, and decision-making through VR-style training.

## Open the prototype

After enabling GitHub Pages, open:

https://aeden333.github.io/qb-sense-vr-prototype/

## Features

- Home dashboard with QB rating, decision time, pressure response, and weekly reps
- Drill library with blitz recognition, pocket pressure, progression reads, red-zone decisions, and two-minute drill
- Live training simulation with a pocket-pressure meter
- Simulated haptic-vest feedback for left, right, or middle pressure
- Coach Mode to select defensive fronts, blitz side, and haptic intensity
- Results screen with AI-style feedback
- Progress tracking

## How to run locally

1. Download or clone this repository.
2. Open `index.html` in Chrome, Safari, Edge, or Firefox.

No installation is required because this is a static HTML, CSS, and JavaScript prototype.
